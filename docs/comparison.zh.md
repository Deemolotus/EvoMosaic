# 混合体 vs Transformer — 这次对照说明了什么

[English](comparison.md)

同一协议快照（modern_v3 对话、只算助手答案、8000 步、Radeon 780M / ROCm）：

| | 进化混合体 | Transformer 基线 |
|--|--|--|
| 结构 | `moe → gru → local_attn → moe` | 7 × 256 因果 Transformer |
| 参数 | 7.05M | 6.92M |
| 验证 NLL ↓ | **3.36** | 3.87 |
| 组句关键词覆盖 ↑ | **0.65** | 0.21 |
| 乱序精确率 ↑ | 0.00 | 0.00 |
| 墙钟 | ~18 min | ~29 min |

权重：`runs/train_modern_moe_attn_v1/best.pt`，`runs/train_transformer_baseline_v1/best.pt`。

## 各自长短

**进化混合体**

- (+) 外环搜索能在小预算下保留 MoE + 局部注意力；
- (+) 本轮：更好的 NLL、更好的关键词绑定、更短墙钟；
- (−) 适应度设计主导结果；乱序能力没有出现；
- (−) 闲聊样本仍不稳（小型字级 LM）。

**Transformer 基线**

- (+) 归纳偏置标准、好讲；
- (+) 满因果注意力原则上擅长绑定提示与答案；
- (−) 在约 7M / 8k 步下：NLL 与关键词覆盖更差，也更慢；
- (−) 乱序精确率同样为 0 — 仅靠注意力不够。

## 教育意义

1. 「进化搜结构 → 梯度练权重」这条流水线在本机 APU 上**能跑通**。
2. 同预算下，搜到的混合栈**不必**输给小 GPT。
3. 进化**不会**自动发明你没写进适应度的技能。
4. 工业界早已用进化 / 种群式 NAS；本仓库是可教学的小样板，不是宣称碾压 AutoML 文献。

## 这不是什么

- 不是「进化普遍优于 Transformer」的证明；
- 不是算子完全同构的对照（局部窗 ≠ 稠密注意力）；
- 不是成品助手 — 乱序复原仍是开放问题。
